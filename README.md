# Управление квадрокоптером Ryze Tello по жестам и позе человека

Проект реализует систему автоматического трекинга человека и управления движениями квадрокоптера Ryze Tello в реальном времени. Система использует две нейросетевые модели архитектуры YOLOv8: одну для отслеживания ключевых точек тела (Pose Estimation), вторую — для классификации управляющих жестов рук.

## Описание работы системы

1. **Инициализация**: Программа подключается к дрону, запрашивает уровень заряда батареи и запускает видеопоток.
2. **Ожидание взлета**: Дрон находится на земле, пока в кадре не будет распознан жест взлета `go_up`.После этого выполняется команда `takeoff`.
3. **Выбор цели (Target Selection)**: Алгоритм анализирует координаты ключевых точек COCO, находит всех людей в кадре, фильтрует их по площади силуэта и близости к центру кадра, выбирая одного наиболее подходящего оператора.
4. **Удержание позиции (Логика позы)**: 
   * Система высчитывает геометрический центр тела оператора. При смещении человека относительно центра кадра за рамки «мертвой зоны» (`DEAD_ZONE_X`, `DEAD_ZONE_Y`), дрон корректирует свое положение (поворачивает влево/вправо, поднимается или опускается).
   * Площадь четырехугольника тела (плечи и бедра) используется для оценки расстояния. Если площадь слишком большая (человек близко) — дрон отлетает назад. Если маленькая (человек далеко) — подлетает ближе.
5. **Распознавание жестов**: Модель классификации жестов обрабатывает каждый кадр и имеет приоритет при выполнении команд смещения вбок (влево/вправо), а также инициирует посадку (`land`) при распознавании жеста `go_down`.

## Используемые технологии и библиотеки

* **Python 3**
* **djitellopy** — библиотека для взаимодействия с API квадрокоптера Tello.
* **ultralytics (YOLOv8)** — инференс моделей компьютерного зрения.
  * Модель `yolov8n-pose.pt` — предобученная модель для оценки позы.
  * Модель `best.pt` — пользовательская обученная модель для классификации жестов.
* **OpenCV (cv2)** — захват, изменение размера, аннотирование и отображение видеопотока.

## Классы жестов

Система поддерживает 5 классов жестов (`GESTURE_CLASSES`):
* `neutral` — отсутствие управляющих команд со стороны рук, удержание позиции по умолчанию.
* `go_up` — команда на взлет (в начале сессии).
* `go_down` — команда на экстренную или плановую посадку квадрокоптера.
* `go_left` — команда на смещение влево (крен).
* `go_right` — команда на смещение вправо (крен).

Минимальный порог уверенности модели для интерпретации жеста задан константой `GESTURE_CONF_THRESH = 0.7`.

## Требования к окружению и установка

Для запуска скрипта необходимо установить зависимости. Рекомендуется использовать виртуальное окружение.

```bash
pip install utralytics djitellopy opencv-python
```

Также в корневой директории скрипта должны находиться файлы весов моделей:
* `yolov8n-pose.pt` (скачивается автоматически при первом запуске через Ultralytics).
* `best.pt` (ваша обученная модель классификации жестов).

## Инструкция по запуску

1. Включите квадрокоптер Ryze Tello.
2. Подключитесь к Wi-Fi сети, создаваемой точкой доступа дрона (обычно имеет имя вида `TELLO-XXXXXX`).
3. Запустите скрипт:
```bash
python main.py
```
4. Встаньте перед камерой дрона. Покажите жест взлета (`go_up`), чтобы запустить полет.
5. Для завершения работы скрипта и экстренной посадки на клавиатуре ПК можно нажать клавишу `q` или комбинацию `Ctrl+C` в терминале.
